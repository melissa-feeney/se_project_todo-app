# Simple Todo App

This is a todo app that will easily track a user's todo items. 

## Functionality

This is an app that allows users to keep track of their daily todos.  One can add items, delete items, and even include due dates. Once an item has been completed, there is a checkbox to show it has been completed. This is a simple, yet very functional app that many might find useful. 

## Technology

For this project, HTML, CSS, and JavaScript are used.  Once the main code was written, I used object-oriented programming to reconfigure the code.  I went through and updated the project's file structure by moving data and configuration objects into a separate file.  I created a separate Class to include the validation code, in FormValidator.js.  I added unique IDs to new to-do items, as well as created a method to reset the form's inputs and disable the submit button.
